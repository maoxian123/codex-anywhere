# 2026-10-21 项目与历史导入验收

本轮在 Windows 10、Python 3.12.3、Node.js 24、Codex CLI/App Server 0.163.0 上验证。真实检查使用独立的回环 Flask 服务、节点状态、SQLite 数据库与测试目录；导入对象为上一轮验收创建的真实 Codex 会话。没有向云端批量上传个人历史。

## 已实现

- 移除项目与图片目录白名单、配对目录字段和相关 CLI 参数；目录访问由节点系统账号的文件权限决定。保留 Codex 原生审批与工作区沙箱。
- 项目按设备和规范化后的目录归类，Windows 路径大小写不敏感。支持浏览远程设备主目录、磁盘与子目录，选择已有目录，或显式创建新目录作为项目。
- 发现本机已有 Codex 会话，支持搜索、归档筛选、工作目录筛选、分页和跨页选择导入；新任务可直接选择项目。
- 导入保留原生会话、消息 ID、未知消息字段和历史顺序，桥接历史输入/输出图片。导入不发起推理；发送新消息时恢复原生会话。
- 元数据和消息双层分页，逐项传输到持久化事件发件箱。兼容不支持新分页接口的旧协议；部分导入失败不会静默重读和重复追加。
- 重复导入更新同一条管理记录，完成后移除本机回滚所淘汰的旧查询投影；原始事件与引用快照保留。
- 历史完成事件可最终确认只读导入，避免结果摘要丢失后把完整历史误判为未知；迟到的旧导入不能覆盖后续对话。

- `.venv/Scripts/python.exe -m pytest -q`：166 项通过，40.74 秒。
- `npm test`：41 项通过。
- Ruff 检查与格式检查、Prettier、TypeScript 与 Vite 生产构建、`git diff --check` 通过。
- 真实 HTTP/WebSocket + 模拟 Codex 子进程覆盖目录创建、跨目录项目、目录列表、分页导入、原生输入/输出图片、重复导入及原会话恢复。
