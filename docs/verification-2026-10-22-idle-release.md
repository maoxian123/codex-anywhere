# 2026-10-22 完成后自动释放验收

## 行为

唯一自动规则为：节点确认最后一轮结束后，用单调时钟计满 120 秒，期间没有新的消息开始下一轮，才卸载该会话。运行、等待原生审批及未完成的控制请求阻止卸载。新一轮开始取消旧计时，其结束后重新计算完整 120 秒。

浏览器不再发送 presence、活动续期或页面退出释放；切换、关闭页面、退出登录和断网不改变节点计时。Hub 对旧 presence 和不含 `manual:true` 的 release 请求返回忽略，节点也忽略已入队的旧命令；删除原有租约过期与五分钟回退策略。

手动释放保留，忙时不排队执行“结束立即释放”；手动接管仍保留进程确认、令牌校验、请求顺序与有效期保护。120 秒是唯一自动释放策略，手动操作的有效期不参与会话持有时间。
