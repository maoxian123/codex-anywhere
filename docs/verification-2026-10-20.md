# 2026-10-20 实际验收记录

本次在 Windows 10（19045）、Python 3.12.3、Codex CLI/App Server 0.163.0 上完成。使用当前用户已登录的 Codex 发起真实推理，管理中心、节点、数据库及项目目录均为独立测试实例。未读取日常项目或其他任务历史。

## 已修复的问题

- 逐条 ACK 曾触发整批未确认事件重复发送，100 个事件逐个确认会产生 5050 帧。现在每连接最多 100 个事件在途，确认释放槽位，至少五秒后才重传，重复确认不触发发送。
- 管理中心改为有界发送队列，由连接所属线程写出；底层帧使用完整、串行写入。重连回放不会持有全局指令锁，且绑定原连接，握手和回放结束后才标记节点在线。
- 补充要求和中断无需等待慢速会话恢复；已失效的审批不能被排队中的回答重新处理。
- 原生错误详情持久化，刷新列表或重新打开任务仍可见。Markdown 已嵌入的图片不会在同一回复中重复展示。
